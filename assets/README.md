# 素材资源目录 · Assets

本目录存放推广页用到的图片与二维码素材。

## 目录说明

| 目录 | 用途 |
| ---- | ---- |
| `images/` | 图文介绍配图：品牌头图、套餐介绍图、场景图等 |
| `qrcode/` | 推广二维码：微信客服码、公众号码、小程序码等 |

## 命名规范

- 统一使用小写英文单词 + 中划线，如 `package-basic-cover.jpg`、`wechat.png`
- 按所属页面加前缀，便于对应：`banner-`（首页头图）、`package-basic-`（基础版）、`qrcode`（二维码）

## 建议尺寸

| 素材 | 建议尺寸 |
| ---- | -------- |
| 首页头图 banner | 1920 × 600 |
| 套餐介绍图 | 1200 × 800 |
| 二维码 | ≥ 500 × 500（正方形） |

图片放好后，到对应 Markdown 页面中把 `![...](...)` 一行的注释取消即可显示。
